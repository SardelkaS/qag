## Why

Сейчас работать с qag можно через браузер и внутренний HTTP API. MCP-сервер позволит совместимому клиенту создавать сценарии, настраивать подключения, проходить проверки и получать отчёты с теми же данными и правилами, что использует UI.

## What Changes

- Добавить Streamable HTTP endpoint `/mcp` в существующий Go-процесс и контейнер на общем локальном HTTP-порту. Поддержать современные и совместимые прежние MCP-клиенты.
- Предоставить типизированные инструменты для всех предметных операций UI: каталог/архив, сценарии и шаги, изображения, окружения/переменные/секреты, HTTP/gRPC/PostgreSQL-ресурсы, TLS/mTLS, proto bundles и источники заголовков, встроенный пример, пробные вызовы, прогоны/очереди/отмена, ручные отметки/комментарии, исследовательские варианты и история.
- Сохранить общие проверки revision, readOnly, снимки, маскирование, idempotency запуска и правила итоговой оценки. Изменения через MCP должны быть видны в UI и наоборот; второй экземпляр владельца БД не запускается.
- Добавить серверное получение PDF, текста, Markdown и оформленных HTML/RTF с изображениями вызовов, включая переключатель ожиданий. Передавать файлы и большие результаты через ограниченные MCP-артефакты с чтением по частям. Явно различать формирование документа и запись в доступный системный clipboard.
- Включать MCP по умолчанию без авторизации, токенов, ограничений Host/Origin/cross-site; разрешить открытый CORS. Все инструменты доступны сразу, а браузерный API сохраняет собственные Host/Origin/CSRF-проверки.
- Добавить в README подключение без настройки доступа, параметры, каталог инструментов, полный пример работы со встроенным кейсом и экспортом, ограничения платформ и повторов. Тема, фокус, прокрутка и несохранённое состояние конкретной вкладки остаются локальными настройками браузера.

## Capabilities

### New Capabilities

- `mcp-server`: локальный MCP endpoint, обнаружение и типизированные контракты инструментов, полное покрытие предметных действий UI, доступ к данным и артефактам, безопасность и совместимость клиентов.

### Modified Capabilities

- `local-app-runtime`: общий процесс UI/API/MCP с раздельной защитой транспортов и документированным MCP-подключением.
- `container-deployment`: включение MCP в штатном контейнере и на существующем опубликованном порту, без дополнительных серверов или инструментов на хосте.
- `run-result-export`: получение всех форматов отчёта сервером без браузера и переносимые артефакты для MCP.

## Impact

Затрагиваются `cmd/qag`, `internal/runtime`, `internal/httpapi`, новый `internal/mcpserver`, существующие `catalog/resources/runs/service`, `internal/reporting`, контрактные проверки и `compose.yaml`. Серверное формирование отчётов использует встроенные шрифты/изображения и Go-зависимости; Node.js и браузер не добавляются в runtime. README и инструкции описывают новый канал. PostgreSQL, исходные SQL `001`–`008`, мастер-ключ, сохранённые JSON и HTTP API сохраняются; MCP не получает произвольный доступ к файловой системе, служебному SQL или управлению Docker.
