## ADDED Requirements

### Requirement: Шапка приложения без бейджа локального режима

Шапка Web UI MUST не показывать бейдж с надписью «Локально». Название и иконка qag, навигация, выбор окружения и переключение темы SHALL сохраняться.

#### Scenario: Обычная шапка
- **WHEN** пользователь открывает приложение в широком окне и меняет тему либо окружение
- **THEN** бейдж «Локально» отсутствует, а остальные элементы шапки доступны
