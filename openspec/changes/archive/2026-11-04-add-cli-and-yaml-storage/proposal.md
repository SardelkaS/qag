## Why

Сейчас qag требует PostgreSQL и предварительной сборки TypeScript, поэтому его нельзя установить одной командой `go install` и запустить с переносимым файлом данных. Нужен самостоятельный консольный запуск того же Web UI/MCP с выбором PostgreSQL либо YAML и переносом данных между ними.

## What Changes

- Добавить установку `go install github.com/SardelkaS/qag/cmd/qag@latest`: готовые UI, иконки и шрифты входят в распространяемый Go-модуль; Node.js и checkout пользователю не нужны.
- Добавить CLI `qag serve`, `qag data export`, `qag data import`, справку и версию. Запуск без подкоманды сохраняет поведение сервера. CLI управляет запуском, настройкой хранилища и переносом; предметные операции доступны в прежних Web UI и MCP.
- Разрешить запуск с подключением к PostgreSQL либо с живым файлом `--data-file`. Без настройки БД нативный запуск использует `./qag.yaml`; явная ошибочная конфигурация БД не переключает приложение на файл.
- Предоставить YAML-хранилище для всего устойчивого состояния: каталог, архив, окружения и версии ресурсов, секреты, изображения, прогоны, попытки, варианты, очереди и данные встроенного примера. Все операции UI/MCP используют выбранное хранилище.
- Сделать единый версионированный YAML одновременно рабочим файлом и форматом переноса PostgreSQL ↔ YAML. Импорт объединяет записи по ID: одинаковые пропускает, новые добавляет; конфликт содержимого либо уникальности отклоняет весь импорт, не заменяя существующие записи.
- Включать в перенос все сохранённые версии и секреты подключений, PEM и proto bundles; изображения хранить внутри файла. В переносимом YAML секреты представлены открытыми значениями, файл получает приватные права; API/MCP и отчёты сохраняют маскирование. При импорте в PostgreSQL секреты шифруются ключом целевой установки.
- В YAML-режиме встроенные HTTP/gRPC читают демонстрационную запись из файла. SQL-шаг остаётся видимым и запускаемым, но получает явную ошибку отсутствующей demo-БД при выполнении. Пользовательские SQL-ресурсы могут обращаться к внешней PostgreSQL.
- Сохранить Compose/PostgreSQL, нативные env-настройки, открытый по умолчанию MCP, историю и действующие SQL-миграции. Дополнить README и эксплуатационные инструкции.

## Capabilities

### New Capabilities

- `cli-distribution`: установка готового приложения через Go, консольные команды и выбор параметров запуска.
- `yaml-data-storage`: полноценное файловое хранилище, его формат, атомарная запись, блокировка и восстановление.
- `portable-data-transfer`: полный экспорт/импорт состояния с секретами, проверкой связей и атомарным объединением по идентификаторам.

### Modified Capabilities

- `local-app-runtime`: два хранилища, проверка готовности и подтверждение записи выбранным backend, инструкции самостоятельного запуска.
- `local-demo-service`: чтение демонстрационных данных из выбранного хранилища и явный отказ встроенного SQL в YAML-режиме.
- `resource-environments`: хранение секретов в YAML и исключение для локального переноса, режим системного SQL-ресурса без БД.
- `expected-result-images`: постоянство байтов эталонов в выбранном хранилище и перенос без внешних файлов.

## Impact

- `go.mod` и внутренние Go-imports: **BREAKING** для сборки со старым путём `qag/...` — модуль получает публичный путь `github.com/SardelkaS/qag`; пользовательские данные и HTTP/MCP-контракты сохраняются.
- `cmd/qag`, `internal/runtime`, `internal/storage`, PostgreSQL-зависимые репозитории `catalog/resources/runs`, `service.Engine`, `reporting`, `httpapi` и `demo`: интерфейсы хранилища и файловая реализация без второго движка исполнения.
- `web/assets.go`, поставка подготовленных frontend-assets, Dockerfile, сборочные и контрактные скрипты: установка из Go module archive без выполнения frontend-сборки на машине пользователя.
- Новый строгий YAML-кодек, платформенные блокировки/приватные права и атомарная замена файла; общий контрактный набор проверок обоих backend и проверки переноса в изолированных схемах существующей PostgreSQL.
- Изменяются только плановые артефакты этого change; реализация начинается отдельным `$openspec-apply-change`.
