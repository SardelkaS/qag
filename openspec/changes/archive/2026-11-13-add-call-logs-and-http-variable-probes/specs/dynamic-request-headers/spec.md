## MODIFIED Requirements

### Requirement: Секретность полученных значений

Извлечённое значение SHALL считаться секретом независимо от имени заголовка. Оно и его полное значение с префиксом и суффиксом, включая JSON/URL/form-экранированные формы, MUST маскироваться в обычных ответах, ошибках, различиях и журналах. Сырой ответ источника и открытое полученное значение MUST не сохраняться в публичном снимке, истории или БД. По call-logs SHALL допускаться диагностическая копия запроса/ответа источника после маскирования выбранного поля, известных секретов и извлечённых значений до записи; невозможность безопасного маскирования SHALL давать явный пропуск тела. Это MUST не восстанавливать значение либо кеш из журнала. Явная проверка переменной по http-variable-probes SHALL иметь отдельное исключение только для временной выдачи скаляра и форматированного значения, без их сохранения либо распространения на обычные вызовы. Настройки SHALL содержать ссылки на сохранённые секреты; такие ссылки SHALL поддерживаться в заголовках и текстовом/JSON/form-urlencoded теле запроса источника, но MUST не допускаться в URL и query. Секреты MUST не читаться из произвольного окружения процесса.

#### Scenario: Основной сервис отражает токен
- **WHEN** основной сервис возвращает извлечённый токен в JSON, заголовке или тексте ошибки
- **THEN** API, интерфейс и сохранённый результат маскируют токен; журнал может показывать лишь диагностическую копию ответа источника после маскирования

#### Scenario: Учётные данные в теле источника
- **WHEN** JSON-тело источника ссылается на секрет окружения или ресурса
- **THEN** значение подставляется только при выполнении, а сохранённая конфигурация и история содержат ссылку вместо секрета

#### Scenario: Отражение полного заголовка
- **WHEN** сервис возвращает `prefix + value + suffix` либо исходный скаляр отдельно
- **THEN** обе формы маскируются в выдаваемых и сохраняемых данных, включая отчёт

#### Scenario: Диагностический ответ источника
- **WHEN** источник вернул корректный JSON с выбранным token и публичным expires_in
- **THEN** журнал сохраняет expires_in и замаскированный token, открытого вычисленного значения в хранилище нет
