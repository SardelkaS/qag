## MODIFIED Requirements

### Requirement: Подготовка без скрытых сетевых действий

Сохранение, чтение настроек, оценка готовности и обычное начало прогона MUST не выполнять HTTP-источники заголовков. Явная команда «Выполнить всё» SHALL запускать последовательность только после устойчивого сохранения прогона и очереди. Все известные ошибки исполнимости, ссылок, переменных и формата источников MUST обнаруживаться до внешнего обращения. Сетевые запросы SHALL начинаться только после явного запуска блока либо очереди и устойчивой регистрации соответствующей попытки, либо после отдельной явной проверки HTTP-переменной по http-variable-probes и устойчивой регистрации проверки. Отказ записи начала попытки MUST предотвращать оба вида запроса. Восстановление после потери процесса MUST не выполнять их автоматически.

Каждый прикладной этап SHALL регистрироваться по call-logs до соответствующего внешнего действия. Проверка HTTP-переменной SHALL выполнять только выбранный источник без основной попытки/прогона и без изменения кеша прогонов. Отказ регистрации проверки или её этапа MUST предотвращать обращение к источнику. Просмотр журнала SHALL оставаться чистым.

#### Scenario: Сохранение и начало прогона
- **WHEN** пользователь сохраняет источник, открывает кейс и начинает прогон без запуска блока или команды «Выполнить всё»
- **THEN** счётчики запросов источника и основного сервиса остаются неизменными

#### Scenario: Отказ регистрации попытки
- **WHEN** PostgreSQL отклоняет запись начала попытки
- **THEN** ни источник заголовка, ни основной сервис не получают запрос

#### Scenario: Отказ записи массового запуска
- **WHEN** PostgreSQL не подтверждает создание прогона или очереди по команде «Выполнить всё»
- **THEN** её вызовы и источники заголовков не запускаются

#### Scenario: Отдельная проверка источника
- **WHEN** пользователь явно проверяет HTTP-переменную без запуска блока
- **THEN** после подтверждённой регистрации проверки выполняется только её источник, основная попытка и прогон не создаются
